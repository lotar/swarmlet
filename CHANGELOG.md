# Changelog

All notable project changes are recorded here.

## [1.0.0-alpha.1] - Unreleased

### Added

- Source-available Swarmlet Community License 1.0.
- Root onboarding, security, contribution, conduct, and release documentation.
- Portable Ubuntu CI with strict TypeScript and hermetic default tests; the same gate is locally verified on macOS.
- Protocol-v2 content-bound tiny-MoE placement epochs.
- Two-physical-owner runner using loopback services and SSH local forwarding.
- Bounded request validation, exact response-set validation, admin-token gating, fail-closed crash proof, supervised restart, and signed evidence.
- Portable FP16 selected-expert bundle format and external Qwen layer-0 owner path.
- Cross-platform RSS, swap, memory, Chrome, path, and Docker-build configuration.
- Dependency-free static `swarmlet.ai` site and optional QA tools.

### Evidence retained

- Real Qwen3.8 Flash Next layer-0 FFN parity.
- Native MTP n=1/3/7 benchmark and concurrency 1/4/8 matrix.
- Disk expert streaming under a 16 GiB envelope.
- No-RAM rollback, feature-cache, scheduler, partition, signed-manifest, comparator, and maintenance artifacts.

### Known limitations

- Physical two-Ubuntu evidence is pending access to both machines.
- Full-model distributed Qwen and Kimi execution are not claimed.
- CUDA execution for portable expert bundles is not implemented.
- Eight-node 50 tok/s results remain simulated and conditional.
- The custom license should be reviewed by qualified software-licensing counsel before public publication.
