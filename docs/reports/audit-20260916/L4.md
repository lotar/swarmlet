## 4. SIMPLIFIED (survivors only)

**S-1 — one memory-first merge, not three.** `bin/gbrain-search-broker.mjs:190-215` (JS),
`src/core/operations.ts:1397-…`, `src/mcp/server.ts:44-…`. All three implement "curated leg +

let the broker call `query` with **no** `source_id` (upstream path already merges server-side) and
