### D1 — `site/install.sh` must refuse to self-upgrade without an explicit flag · **A** · the file is 8,296 B

* **Risk if I am wrong:** none — behaviour is observed, not inferred.
* **Restore:** n/a (behaviour fix).
* **Proposed shape:** refuse unless `--yes`/`SWARMLET_UPGRADE=1`, or when the box already runs the release the bundle ships (here it did: `releaseSequence 2026091225` both before and after). Also add `--help`.
* **Class of follow-on:** this is the **only** place a script in this lane can restart production by accident. Worth a `if [ -z "$CODE" ] && [ "$_have_identity" = 1 ]` usage branch.
